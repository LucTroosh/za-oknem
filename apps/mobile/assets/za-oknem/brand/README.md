# Brand marks

- `logo-mark.svg` — approved vector source (flat gradient tile).
- `logo-mark-512.png`, `-256`, `-1024` — approved raster pack (glossy window mark), used for launcher-style contexts.
- `logo-mark-flat-512.png` — transparent 512 px render of `logo-mark.svg` (no new design; rendered with
  Chromium, `omitBackground`), used on the Welcome screen so the mark sits flat on the photo instead of
  looking like a glossy sticker. Regenerate from the SVG if the SVG ever changes.
